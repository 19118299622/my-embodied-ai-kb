# 离线质量评分器作为强化学习奖励的分层设计

> 本文记录用户当前形成的技术框架，不等同于已验证的完整方案。

## 三类信号

把离线质量评分器迁移到强化学习奖励设计时，至少需要区分三种信号：

1. **任务完成 / 进度信号**：根据视觉和语言判断任务完成程度，回答“现在离目标还有多远”。
2. **过程质量信号**：描述轨迹是否平滑、动作是否异常、阶段之间是否一致，以及动作后果是否符合预期。
3. **训练价值信号**：回答一段数据或一次交互对当前策略是否真的有学习价值。

它们都可能进入 reward design，但作用不同：任务进度更接近目标导向奖励；过程质量更适合作为约束或 shaping；训练价值则依赖当前策略和数据分布，未必适合直接逐步加入环境奖励。

## 组合式设计倾向

如果以后把现有的数据质量评估系统迁移到强化学习后训练，更倾向于采用组合式设计：

- 主奖励负责表达任务目标；
- 进度类信号用于缓解稀疏奖励；
- 过程质量类信号作为辅助 shaping 或 penalty；
- 数据价值类指标更多用于采样、筛选或 replay weighting，而不是直接当作环境奖励。

## 风险与开放问题

需要特别防止 reward hacking：如果某个代理指标容易被策略单独优化，就不能因为它和“高质量轨迹”相关，就默认它等价于真实任务目标。

这条框架目前尚未形成完整方案；episode 级信号如何分配到 step-level reward，以及多个局部指标如何避免被策略投机优化，仍需进一步定义和验证。
