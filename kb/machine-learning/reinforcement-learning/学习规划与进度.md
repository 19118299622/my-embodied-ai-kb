# 强化学习基础学习规划与进度

> 本文件夹采用双文档学习模式：本文件记录规划与进度，[`长期学习笔记.md`](./长期学习笔记.md) 沉淀具体内容。
> 学习节奏：完成一讲 → 进入问答区 → 澄清关键疑问 → 把结论和误区修正写回笔记 → 再进入下一讲。

## 1. 学习目标

1. 能用马尔可夫决策过程（Markov Decision Process，MDP）形式化描述机器人策略学习问题；
2. 理解策略梯度类方法的基本动机与 REINFORCE 的梯度估计；
3. 掌握优势函数（Advantage Function）与广义优势估计（Generalized Advantage Estimation，GAE）的推导与直觉，尤其是长时序任务中的信用分配（credit assignment）；
4. 完整理解近端策略优化（Proximal Policy Optimization，PPO）的裁剪替代目标、价值损失、多轮（multi-epoch）更新与 KL 早停；
5. 把 RL 基础与当前研究主线（VLA 后训练）连接起来：理解 RIPT-VLA 的 DS-LOOP（RLOO 留一法优势 + PPO 裁剪 + 动态采样）、GRPO、RLOO 这类「组内相对优势估计」为何是 PPO 价值函数路线的变体。

## 2. 前置知识

- 概率基础：期望、对数导数（似然比技巧）；
- 自动微分与 PyTorch 基础；
- 一点最优控制 / 动态规划直觉（可选）；
- 已读过 [`../../../docs/03_papers/ript_vla/RIPT-VLA_阅读笔记.md`](../../../docs/03_papers/ript_vla/RIPT-VLA_阅读笔记.md) 的 §4–§6（VLA 三阶段训练与 DS-LOOP），作为应用背景。

## 3. 总体路线

```mermaid
flowchart LR
    A[MDP 与 RL 问题设定] --> B[策略梯度 / REINFORCE]
    B --> C[优势函数与 GAE]
    C --> D[PPO 精解]
    D --> E[组内相对优势: RLOO / GRPO / DS-LOOP]
    E --> F[与 VLA 后训练衔接]
```

## 4. 阶段划分

- **阶段一（RL 问题设定与基础）**：MDP、回报、策略、值函数；策略梯度与 REINFORCE；优势函数与 GAE；PPO 精解。
- **阶段二（组内相对优势与 VLA 后训练衔接）**：RLOO / GRPO / DS-LOOP 的谱系；稀疏二元奖励下的优势估计；与 RIPT-VLA 笔记联动。
