# L1 核心精读总结：具身模仿学习的数据质量与数据分配

> 更新日期：2026-07-17  
> 范围：`Data Quality in Imitation Learning`、`Data Assessment for Embodied Intelligence` 与正在精读的 `Robot Data Curation with Mutual Information Estimators`。公式、图表和逐项证据保留在各论文笔记。

## 核心定义

在固定训练与评测协议下，数据质量是数据是否提供可辨识、可执行、有效覆盖且与目标任务匹配的状态—动作规律，并能在闭环中转化为策略性能。

```text
数据质量：样本自身是否一致、可预测、完整且有有效变化？
数据分配：有限训练预算应如何在任务、轨迹或片段之间筛选、加权或配比？
```

质量分数是分配决策的输入，不等于分配策略；“高分数据”必须经同预算下游实验验证。

## 四层框架

| 层 | 关键问题 | 候选信号 | 已读证据与边界 |
|---|---|---|---|
| 数据集/任务 | 有没有非冗余、可迁移的任务覆盖？ | 表征熵、空间/方向覆盖、任务比例、任务相似性 | `Data Assessment` 的 Diversity Entropy 与 Learnability；[PAPER] 主要基于三帧视觉表征，不能直接判断动作合法性。 |
| 轨迹 | 整段示教是否可形成稳定控制规律？ | 局部动作一致性、转移多样性、state-action MI、时序完整性 | `Data Quality in IL` 关联闭环状态分布；DemInf 把逐对估计聚合为轨迹排序。 |
| 片段/时间步 | 哪些局部行为异常、冗余或难预测？ | 动作方差、条件熵、局部 MI、进展/停顿 | [INFERENCE] 可诊断，不能直接按时间步低分删除：关键接触阶段本来难预测。 |
| 任务相关价值 | 对目标策略是否真实有增益？ | 留出任务成功率增益、影响/价值估计 | [PAPER] `Data Assessment` 以固定 OpenVLA-7B + LoRA 协议校验，价值仍依赖模型与协议。 |

## 两条主线

### Data Quality：可学习的状态—动作规律

- [PAPER] `Data Quality in Imitation Learning` 将质量联系到学习/示教策略的状态访问分布偏移，强调**动作一致性**与适度**转移多样性**，不把状态多样性直接等同质量。
- [PAPER] 高动作噪声令相似状态对应冲突动作；适度动力学变化可扩大有效覆盖，过量或稀疏覆盖会损害学习。
- [INFERENCE] VLA 的邻域与一致性宜建在任务相关多模态表征上，而非原始像素距离。

### Data Assignment：把质量转化为可验证取舍

- [PAPER] `Data Assessment` 用数据集级 Diversity Entropy 描述丰富度，以 task-level Learnability 预测固定协议下的成功率增益；它支持任务级采集/配比，不定位单条坏轨迹。
- [PAPER] Learnability 同时刻画可记忆性、表达性、任务间相似性和任务配比，说明“样本多”不等于“分配合理”。
- [INFERENCE] 分配至少应共同约束有效覆盖、局部控制一致性、任务配比及下游收益；单一排序会牺牲长尾任务或关键接触片段。

## 初始统一准则

```text
局部 state → action 可辨识（低冲突/低条件不确定性）
→ 动作随状态有效变化（避免恒定动作）
→ 任务与环境有效覆盖
→ 同预算下游验证优于随机子集与全量数据
```

Mutual Information 路线刻画其中前两项：

`I(S; A) = H(A) − H(A | S)`

它不衡量任务成功、阶段进展、安全、跨模态标签正确性，需与成功筛选、进展检测及下游评测配套。

## 当前方法矩阵

| 方法 | 主粒度 | 定义 | 分配动作 | 关键局限 |
|---|---|---|---|---|
| Data Quality in IL | 数据集、state-action | 状态访问对齐；动作一致性与转移多样性 | 诊断性代理指标 | 不直接给自动筛选器；邻域/表征敏感。 |
| Data Assessment | 数据集、任务 | 表征熵 + 固定协议下可学习性 | 数据集画像、任务级配比建议 | 三帧视觉不直接审计控制质量；价值依赖模型。 |
| DemInf（进行中） | state-action → 轨迹 | `I(S; A) = H(A) − H(A | S)` 的样本贡献 | 轨迹排序、阈值筛选 | 假设成功；可能偏好可预测停顿。 |

## 后续 L1 检查清单

1. 评分衡量可学习性、覆盖、进展、异常还是任务价值？
2. 分数在哪个粒度算、在哪个粒度筛选/加权？
3. 如何避免误删任务关键但本来难预测的片段？
4. 是否和等量随机子集、全量数据、强基线在同训练预算下比较？
5. 成功标签、任务条件、模态、数据量、计算成本的失效前提是什么？
