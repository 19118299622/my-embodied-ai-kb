# 数据集质量评估调研：分层阅读计划

> 制定日期：2026-07-16  
> 适用范围：`papers/` 中已完成摘要／结论级初筛的 27 篇唯一主题论文。  
> 当前阶段：从“文献分类初筛”进入“核心方法比较”。初筛定位不是对论文方法、公式或实验结论的完整核验。

## 调研目标与完成标准

本调研不以“读完全部论文”为目标，而是形成一个可执行的数据集质量评估框架：

```text
数据有什么问题？ → 用什么可计算信号量化？ → 如何评分／筛选？ →
筛选结果是否在下游策略、鲁棒性或泛化评测中得到验证？
```

完成第一阶段的标准是：

1. 明确候选质量维度、评估粒度和所需输入字段；
2. 对每个维度至少保留一篇有方法与实验依据的核心论文；
3. 区分通用质量信号、任务相关数据价值与外部验证协议；
4. 选出一个可在后续数据条件下进行静态审计或最小验证的候选指标。

## 两套标签：分类与阅读层级

调研地图的 A–E 主分类回答“论文在知识版图中的位置”；本计划的 L0–L3 回答“当前需要读到什么深度”。两套标签并行记录，不互相替代。

| 地图主分类 | 作用 | 对应阅读层级 |
|---|---|---|
| A：直接质量评估与数据筛选 | 质量定义、指标、排序、删除、重加权及下游收益证据 | 优先进入 L1；其余留在 L2 |
| B：数据资源与采集质量 | 覆盖、同步、标定、动作接口与模态完整性等输入质量代理量 | L2；只在缺少相应质量维度时定向阅读 |
| C：生成与扩增数据质量 | 结构保持、物理可行性、过滤与生成失败模式 | L2；用于扩增或合成数据场景 |
| D：外部验证与评测协议 | 长时程、扰动、sim-to-real 与泛化验证 | L3；在设计验证方案时重点阅读 |
| E：综述与参考地图 | 资源定位、术语和引用链 | L3；REFERENCE_ONLY，按需回查 |

| 阅读层级 | 阅读范围与输出 | 当前对象 |
|---|---|---|
| L0：初筛 | 摘要、结论／局限与基本身份信息；记录主分类、可复用问题和优先级 | 27 篇唯一主题论文已完成摘要／结论级定位 |
| L1：核心精读 | 方法、关键公式、主实验、局限；建立论文卡、证据表和矩阵行 | `Data Quality in Imitation Learning`、`Data Assessment for Embodied Intelligence`、`Robot Data Curation with Mutual Information Estimators`、`SCIZOR`、`CUPID`、`DataMIL`、`SIEVE` |
| L2：定向补充 | 仅读能补齐缺口的章节与实验；提取一个明确的质量维度或边界 | PSD、ISR、QoQ、ATHENA、DSL、IQA、COBALT、MinInter，以及 B/C 类材料 |
| L3：参考与验证 | 只提取数据条件、评测协议、适用范围或引用线索，不重复方法精读 | D 类基准、E 类综述及其余资源论文 |

## 论文阅读顺序

### 第一批：定义与可筛选信号

1. `Data Quality in Imitation Learning`：补齐理论定义、动作一致性估计和实验边界。
2. `Data Assessment for Embodied Intelligence`：核对数据集级多样性／可学习性指标与下游证据。
3. `Robot Data Curation with Mutual Information Estimators`：确认状态—动作互信息的估计、评分粒度、筛选规则与验证。
4. `SCIZOR`：补齐 transition 级自监督检测、冗余识别与筛选证据。

### 第二批：任务相关价值与长程结构

5. `CUPID`、`DataMIL`：比较影响函数与 datamodels 如何定义“对特定任务有价值的数据”。
6. `SIEVE`：补齐长时程行为原语、转接结构和覆盖度的质量信号。

### 第三批：按缺口定向补充

- 时序平滑／冗余：PSD、ISR。
- 任务相关贡献与可扩展性：QoQ、ATHENA。
- 覆盖与采集设计：DSL、COBALT，以及 B 类资源论文。
- 视觉输入与合成数据：IQA、MinInter，以及 C 类生成论文。
- 验证协议：COLOSSEUM、CALVIN、SIMPLER、VLABench。

## 每篇 L1 论文的最小证据记录

仅当以下问题可由原文回答时，才继续投入精读时间：

1. 质量被定义为哪种可观测或可估计的量？
2. 评分发生在数据集、任务、轨迹、片段还是时间步？
3. 输入需要哪些字段，哪些字段在目标数据中可能缺失？
4. 输出是分数、排序、过滤列表还是数据权重？
5. 是否在控制数据量、模型或任务条件下验证了下游收益？
6. 证据来自仿真、实机还是离线相关性？
7. 该方法的假设、计算成本和失效情形是什么？

若摘要、方法图和主实验仍无法回答其中大部分问题，则将论文降为 `REFERENCE_ONLY` 或 L2，不再撰写长笔记。

## 后续实验门槛

在完成第一版比较矩阵前，不启动大规模数据下载或训练。选定候选指标后，先进行：

1. Level 0：静态审计（字段、公式、代码路径和计算量）；
2. Level 1：小样本／单批次计算或 smoke test；
3. Level 2：最小对照实验（随机抽样 vs. 按质量筛选）；
4. Level 3：仅在资源、数据许可和价值明确后开展完整复现。

任何大规模下载、训练或依赖替换前，先给出资源估算并取得确认。
