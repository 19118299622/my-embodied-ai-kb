## 2. 研究背景与动机

### 2.1 具身智能的碎片化困境

当前具身智能研究面临严重的**碎片化（fragmentation）**问题：

- **操作模型**（如 π0 [Black et al., 2024]、GR00T N1 [NVIDIA et al., 2025]）专门针对桌面操作或灵巧控制训练。
- **导航模型**（如 NaVid [Zhang et al., 2024]、Uni-NaVid [Zhang et al., 2025b]）专门设计用于室内环境的路径规划。
- **人类自我中心模型**针对手腕/手部轨迹预测。

这些模型各自为政，无法在不同任务家族、环境和机器人实体（embodiment）之间迁移。这使得具身学习难以像通用视觉-语言预训练那样规模化扩展。

### 2.2 统一建模的动机

论文的核心洞察在于：尽管具身决策任务在表面形式上差异巨大（末端执行器位姿 vs 关节位置 vs 路径点），但它们共享一个**共同的底层计算结构**——智能体必须基于视觉观测、语言指令和实体特定约束，预测未来动作或轨迹。

这促使论文提出一个**统一形式化**：将操作、导航和轨迹预测全部纳入同一个动作与轨迹预测框架中。

---

## 3. 核心贡献

1. **统一的 VLA 模型**
   - 将操作（manipulation）、导航（navigation）和人类自我中心动作建模统一到共享的动作与轨迹空间中。
   - 基于 Qwen3.5-4B VLM backbone + DiT 流匹配策略头。

2. **大规模联合预训练数据**
   - 构建了异构数据源的混合预训练语料，包括：机器人操作轨迹、人类自我中心演示、合成仿真数据、导航数据和精选视觉-语言数据。

3. **具身感知提示条件（Embodiment-aware Prompt Conditioning）**
   - 通过文本描述来指定当前机器人平台、控制约定和预测时域，使单一模型支持多种机器人平台，无需为每种实体维护独立策略。

4. **渐进式训练管线**
   - T2A → CPT → SFT → RL 四阶段训练，弥合离散 VL token 与连续动作轨迹之间的鸿沟。

5. **跨域泛化验证**
   - 在操作、导航、分布外鲁棒性和跨实体泛化等多个维度进行了系统评估。

## 4. 方法详细描述

### 4.1 统一问题形式化

Qwen-VLA 将所有任务形式化为统一的**条件预测框架**。在时刻 t，模型接收：

- **视觉上下文** `o_t`：一帧或多帧图像/视频观测
- **语言指令** `x`：任务描述
- **实体描述** `e`：文本提示，描述当前机器人平台和控制约定
- **可选任务标识符** `z`：标识任务家族

模型被训练以预测目标序列 `y_{t:t+H-1}`，在 H 步预测时域上：

> p_θ(y_{t:t+H-1} | o_t, x, e, z)

其中 `y_{t:t+H-1}` 的内容取决于任务类型：

| 任务类型 | y 的含义 |
|---------|---------|
| **操作** | 未来机器人动作（如末端执行器位姿） |
| **导航** | 导航决策或路径点（waypoints） |
| **轨迹预测** | Agent 或周围实体的精确未来空间轨迹 |
| **自我中心数据** | MANO 手部模型参数或骨骼关节序列 |

### 4.2 模型架构

**整体架构总览**：

**架构解读**：

Qwen-VLA 的架构设计遵循"**强 Backbone + 专用动作专家**"的分工模式：

- **上半部分——Qwen3.5-4B Backbone**：负责所有高层认知任务。它接收视觉观测和语言指令，通过 ViT+LLM 的交叉注意力融合产生**条件表示 h_t**。这个表示编码了场景语义、物体空间关系、任务意图以及实体特定约束（通过 Embodiment Prompt 注入）。Backbone 本身不做任何动作预测——它只负责"理解"。

- **下半部分——DiT 流匹配动作解码器**：负责将 Backbone 的"理解"转化为具体的连续动作。它采用流匹配（Flow Matching）而非标准扩散——通过学习速度场将随机噪声逐步变换为动作序列。AdaLN（自适应层归一化）将条件 h_t 注入每个 DiT Block，使生成的动作与当前任务上下文对齐。

- **统一输出头**：同一个 DiT 解码器输出不同任务类型的动作（操作/导航/轨迹），不做架构切换。这是 Qwen-VLA "统一"承诺的工程实现——不是多个专家模型的组合，而是单一模型在单一前向传播中处理不同任务。

Qwen-VLA 由两个核心组件组成：

**视觉-语言 Backbone**：
- 基于 **Qwen3.5-4B**，一个原生多模态模型。
- 提供**细粒度视觉感知**、**鲁棒的指称定位（referential grounding）**、**多语言指令跟随**和**结构化推理**能力。
- 这些能力对于需要解释空间关系、识别指称物体和遵循复杂多步指令的具身任务至关重要。

**DiT 流匹配动作解码器（Flow-Matching Action Decoder）**：
- 在 backbone 之上附加一个基于 **DiT（Diffusion Transformer）** 的流匹配策略头。
- 专门负责**细粒度的连续动作生成**。
- 流匹配（flow matching）是一种现代生成建模方法，通过学习速度场将简单噪声分布变换为目标动作分布。

**关键架构决策**：不为不同实体设计分离的输出头或任务特定架构。操作动作、导航路径点、人类自我中心运动都在**共享的动作与轨迹预测空间**中表示，单一模型即可吸收来自不同具身数据集的监督信号。

### 4.3 具身感知提示条件（Embodiment-aware Prompt Conditioning）

这是 Qwen-VLA 实现跨实体泛化的核心机制。

**机制**：
- 每个训练样本前缀一个**文本描述**，包括：
  - 机器人平台名称（如 "Franka Panda", "Mobile ALOHA", "WidowX"）
  - 手臂配置（单臂/双臂）
  - 控制约定（delta EEF vs absolute joint）
  - 控制频率
  - 预测时域
- 此提示是模型了解实体特定控制语义的**唯一接口**。

**效果**：
- 同一动作解码器可以处理不同控制模式（位置/速度/关节）、不同动作维度和不同时间尺度，无需改变模型架构。
- 模型可以在异构实体上学习**共享的视觉定位和空间推理能力**，同时尊重平台特定的动作约定。

### 4.4 统一动作与轨迹表示

Qwen-VLA 不将所有数据转换为单一动作格式，而是**保留每个数据集的原始动作约定**：

- 部分数据集提供 Cartesian 空间的绝对末端执行器位姿
- 部分提供 delta 末端执行器指令
- 部分使用绝对或相对关节空间控制信号

**量纲归一化（Quantile Normalization）**：
- 对每个数据集的每个动作维度，计算第 1 和第 99 百分位数
- 应用线性映射到 [-1, 1]
- 这消除了不同实体和动作空间的尺度差异，同时保留各数据源内的相对运动结构

**支持的动作类型**（Table 2）：

| 机器人 | 手臂 | 动作类型 |
|--------|------|---------|
| WidowX | 单臂 | ΔEEF + Gripper |
| Google Robot | 单臂 | ΔEEF + Gripper |
| Franka Panda | 单/双臂 | ΔEEF + Gripper; Abs Joint + Gripper |
| ARX5 | 双臂 | ΔEEF + Gripper |
| Mobile ALOHA | 双臂 | ΔEEF + Gripper; Abs Joint + Gripper |
| AgiBot A2-D | 双臂 | Abs Joint + Gripper; Abs Joint + DH |
| Galaxea R1 | 双臂 | Abs Joint + Gripper |
| 真实人类 | 双手 | ΔEEF (来自 MANO 模型) |

## 5. 训练策略：四阶段渐进式训练

Qwen-VLA 的训练管线是其最核心的技术贡献之一。由于 VLM backbone 已具备通用视觉-语言表示能力，而 DiT 动作解码器是随机初始化的，直接将两者联合训练会浪费算力且可能破坏预训练表示。

论文提出了一个**压缩视角（compression view）**的训练策略：

> "一个语言指令（如'拿起红色杯子'）仅用少量 token 就能紧凑编码任务意图，但对应的动作轨迹可能跨越数百个高维关节位置值。弥合这一维度差距是一个结构化解压缩问题。"

**四阶段训练管线总览**：


**管线解读**：

四阶段设计的关键在于**逐步增加复杂度，避免"冷启动"灾难**：

- **T2A → CPT**（"先学解压，再学看图"）：这是最巧妙的阶段衔接。如果一开始就让随机初始化的 DiT 解码器同时处理视觉和动作，它会浪费大量算力去学习"如何从随机状态输出合理动作"这一基础能力。T2A 阶段先用最简单的条件（纯语言）教会解码器最基本的动作解压缩，CPT 阶段再加入视觉信号，解码器只需学习"如何将视觉信息融入已有的解压能力"——这比从头学起容易得多。消融实验也验证了这一点：T2A 仅需 2000 步即达峰值。

- **CPT → SFT**（"从广阔覆盖到精准对齐"）：CPT 提供跨域、跨实体的广泛覆盖，但输出不够精确。SFT 用高质量示范进行对齐，分为两条路径——多任务路径保持通用性，真实部署路径测试迁移能力。

- **SFT → RL**（"从模仿到优化"）：这是 Qwen-VLA 区别于大多数 VLA 方法的关键。SFT 优化的是"像不像示范"，而 RL 直接优化"能不能成功"。论文刻意将 RL 限制在单一仿真环境（SimplerEnv），结果却能泛化到多个分布外基准——说明 RL 优化的不是环境特定的"作弊"策略，而是通用的闭环执行能力。

### 5.1 阶段一：文本到动作DiT预训练（T2A）

**Text-to-Action DiT Pretraining (T2A)**

- **目标**：在引入任何视觉输入之前，教会动作解码器充当**语言条件的动作解压缩器**。
- **做法**：仅使用语言指令和实体提示（不含视觉 token）作为条件，训练 DiT 解码器预测动作轨迹。
- **效果**：解码器学会了从紧凑的语言编码"解压"出完整动作序列，建立了**压缩的动作先验**。
- **消融关键发现**：
  - 全序列预测优于块预测（+4.94 pp）
  - T2A 阶段不应包含图像 token
  - 约 20% 合成数据 + 80% 真实数据（不含图像）是最优组合
  - T2A 训练 2000 步即达峰值性能

### 5.2 阶段二：多模态持续预训练（CPT）

**Continued Pretraining (CPT)**

- **目标**：将 T2A 阶段学到的压缩动作先验**视觉接地**（ground in visual observations）。
- **做法**：在异构数据混合上联合训练 VLM backbone 和动作解码器。
- **关键属性**：CPT 的输出检查点同时暴露于仿真和真实机器人数据域，这对后续后训练阶段至关重要。

### 5.3 阶段三：监督微调（SFT）

**Supervised Fine-Tuning (SFT)**

CPT 之后分叉为两条并行路径：

**路径一：多任务 SFT**
- 在异构任务上联合微调：视觉问答、空间定位、操作、导航
- 采用实体平衡（embodiment-balanced）和任务平衡（task-balanced）采样

**路径二：真实世界部署 SFT**
- 从 CPT 检查点出发，在内部遥操作数据上微调
- 测试 CPT 的跨域先验是否能迁移到物理硬件

### 5.4 阶段四：强化学习（RL）

**Reinforcement Learning**

- **目标**：直接优化闭环任务成功率（而非模仿似然度）。
- **算法**：PPO（Proximal Policy Optimization）+ GAE（Generalized Advantage Estimation）
- **奖励**：稀疏二值奖励（任务成功=1，否则=0）
- **RL 环境**：仅在单一仿真环境（SimplerEnv）中收集 rollout
- **设计哲学**：刻意使用狭窄的 RL 设置，测试在一个仿真环境中获得的成功改进能否迁移到其他分布外环境

**RL 的关键技术细节**：

| 参数 | 值 |
|------|-----|
| 动作块长度 H | 16 |
| 并行环境实例 | 128 |
| 折扣因子 γ | 0.99 |
| GAE trace-decay λ | 0.95 |
| PPO clip ε | 0.2 |
| Actor 学习率 | 5×10⁻⁶ |
| Value 学习率 | 10⁻⁴ (~20× actor LR) |

**流匹配下的对数概率估计**：由于流匹配模型不直接输出概率分布，论文将确定性概率流 ODE 转换为对应的 SDE，在每个 Euler 去噪步注入受控噪声，使得每一步变为显式高斯分布，可解析计算 log-probability。

**出域泛化**：RL 仅需替换实体提示即可零样本迁移到分布外环境和实体，无需额外适配头或域特定微调。

## 7. 实验与评估

### 7.1 操作仿真评估

Qwen-VLA 在四个仿真基准上进行了评估（Table 4）：

| 方法 | 类型 | LIBERO | RoboCasa-GR1 | Simpler-WidowX | RoboTwin-Easy | RoboTwin-Hard |
|------|------|--------|-------------|----------------|---------------|---------------|
| π0 | 专家 | 94.4 | – | – | 65.9 | 58.4 |
| StarVLA-OFT | 专家 | 96.6 | 48.8 | 64.6 | 50.4 | – |

**核心发现**：单一通才模型超越了大多数专家模型：
- **LIBERO**: 97.9%（与最佳专家 ABot-M0 的 98.6% 几乎持平）
- **RoboTwin-Hard**: **87.2%**（超越所有专家模型，包括 ABot-M0 的 85.0%）

### 7.2 导航评估

| 基准 | 指标 | Qwen-VLA-Instruct |
|------|------|------------------|
| **R2R**（Room-to-Room） | OSR（Oracle Success Rate） | **69.0%** |
| **RxR**（Room-across-Room） | SR（Success Rate） | **59.6%** |

导航评估展示了 Qwen-VLA 将操作学习到的空间推理能力迁移到导航任务的能力。

### 7.3 分布外泛化（DOMINO动态操作）

**DOMINO** 是一个动态操作基准，包含 35 个 test suite，物体在操作过程中持续移动。这要求模型拥有对运动物体的零样本动态操作能力，而非执行记忆化的静态例程。

| 方法 | 成功率（SR） | 操作得分（MS） |
|------|------------|--------------|
| OpenVLA-OFT | ~7% | – |
| π0.5 | ~7% | – |
| LingBot-VA | – | – |
| PUMA（DOMINO 专用微调） | 17.2% | 35.0 |
| **Qwen-VLA-Instruct**（零样本） | **26.6%** | **39.5** |

**关键发现**：
- Qwen-VLA 在**零样本**设置下（仅使用当前帧观测，无动态操作微调）超越所有 baseline。
- 超越 PUMA（DOMINO 专用微调方法）9.4 个百分点（SR），而 PUMA 使用了 DOMINO 特定微调和时序运动输入。
- 这一结果归功于统一动作与轨迹预训练策略学到的**可迁移空间-运动学先验**。

### 7.4 真实世界ALOHA实验

在 ALOHA 双臂机器人上的实验验证了 Qwen-VLA 的分布外泛化能力：

**四类 OOD 设置**（所有均为零样本操作）：

| 设置 | 描述 | 结果 |
|------|------|------|
| **颜色定位** | 抓取指定颜色的球（绿/蓝/红/黄） | 四色全部成功 |
| **新物体抓取** | 抓取训练数据中未出现的物体（西兰花、玩具鸭） | 成功定位，抓取受限于不规则形状 |
| **组合清理任务** | "清理桌面"：依次将雨伞、玩具鸭、酸奶瓶放入收纳箱 | 完整执行三个物体的序列操作 |
| **未见物体交互** | "接近"指令 + 训练中不存在的物体（墨镜、毛绒玩具） | "接近"动作本身几乎不在操作数据中，模型正确解释指令 |

这些定性结果验证了 VL-VLA-VLN 联合训练的价值：视觉-语言数据为模型暴露了更广泛的物体词汇，该词汇可迁移到操作任务中。

### 7.5 消融实验

**T2A 阶段消融**（Figure 6）：

## 8. 结论与局限性

### 主要结论

1. **统一建模可行**：操作、导航和轨迹预测可以在单一 VLA 模型中统一处理，且通才模型可以超越专家模型。
2. **渐进式训练管线有效**：T2A → CPT → SFT → RL 四阶段训练成功弥合了离散 VL token 与连续动作轨迹之间的鸿沟。
3. **实体提示条件机制**：仅通过文本提示即可实现跨多种机器人平台的零样本泛化。
4. **联合预训练的价值**：异构数据源的联合预训练产生了可迁移的视觉定位、空间推理和连续控制先验。

### 局限性

- **RL 仅在仿真中进行**：真实世界的 RL 微调尚未探索。
- **动态操作仍是挑战**：DOMINO 26.6% 的零样本成功率虽然领先，但距离实用仍有差距。
- **缺乏力/触觉反馈**：模型仅使用视觉和语言，未利用力觉、触觉等丰富的物理反馈。
- **长程部署稳定性**：长时间运行的错误累积和故障恢复仍是开放挑战。
