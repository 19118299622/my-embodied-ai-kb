## 1. ε 的精确数学语义

PPO 的裁剪目标函数：

$$\mathcal{L}_{\text{PPO}} = -\min\left( r \cdot A,\ \text{clip}(r, 1-\varepsilon, 1+\varepsilon) \cdot A \right)$$

其中 $r = \frac{\pi_\theta(a|c)}{\pi_\psi(a|c)}$。

### 1.1 两种情况的逐项分析

**情况一：正优势 $A > 0$（好动作，应增大其概率）**

$r > 1$ 是期望方向（增大概率）。$\min(\cdot, \cdot)$ 取两者中较小者：

| r 的值 | 裁剪行为 | 梯度效果 |
|--------|---------|---------|
| $r \in [1, 1+\varepsilon]$ | $\min(rA, rA) = rA$ | 完整梯度，不被裁剪 |
| $r > 1+\varepsilon$ | $\min(rA, (1+\varepsilon)A) = (1+\varepsilon)A$ | 梯度截断，停止增大 |
| $r < 1$ | $\min(rA, (1-\varepsilon)A) = rA$ | 不做约束（概率在减小，不违背"鼓励"意图） |

```
A > 0 时的目标函数曲线：
           │
  L_PPO    │       ╱  r·A (未裁剪)
           │      ╱
           │     ╱
           │    ╱              ← ε 处开始平坦：梯度为零
           │   ╱    ┌──────────── (1+ε)·A (裁剪后)
           │  ╱    ╱
           │ ╱    ╱
           │╱____╱
           └──────────────── r
           0   1  1+ε
```

**情况二：负优势 $A < 0$（坏动作，应减小其概率）**

$r < 1$ 是期望方向（减小概率）。但注意 $A$ 为负，所以 $\min(\cdot, \cdot)$ 取"更小"（即更负、绝对值更小）的值：

| r 的值 | 裁剪行为 | 梯度效果 |
|--------|---------|---------|
| $r \in [1-\varepsilon, 1]$ | $\min(rA, rA) = rA$ | 完整梯度，不被裁剪 |
| $r < 1-\varepsilon$ | $\min(rA, (1-\varepsilon)A) = (1-\varepsilon)A$ | 梯度截断，停止惩罚 |
| $r > 1$ | $\min(rA, (1+\varepsilon)A) = rA$ | 不对好方向做负向约束 |

### 1.2 ε 的本质

**ε 定义了策略在一次 PPO 迭代中允许的最大相对变化幅度**。超过 $1 \pm \varepsilon$ 的重要性比率被视为"过度偏离采样分布"，其梯度信号被截断。

## 2. ε 与信任区域理论

ε 继承了 TRPO（Trust Region Policy Optimization）的思想，但用简单的 clip 替代了复杂的二阶约束优化。

### 2.1 ε 与 KL 散度的近似关系

当策略更新幅度不大时，重要性比率 r 与 KL 散度有如下近似：

$$D_{KL}[\pi_\theta \| \pi_\psi] \approx \frac{(r-1)^2}{2}$$

若 $r = 1 + \varepsilon$，则：

$$D_{KL} \approx \frac{\varepsilon^2}{2}$$

| ε | 近似 KL 上限 | 更新激进程度 |
|---|-------------|------------|
| 0.05 | ~0.0013 | 极其保守 |
| 0.1 | ~0.005 | 保守 |
| **0.2** | **~0.02** | **标准（PPO 默认）** |
| 0.3 | ~0.045 | 较激进 |
| 0.5 | ~0.125 | 激进（高风险） |

TRPO 通常约束 $D_{KL} \le 0.01$，所以 PPO 的 $\varepsilon=0.2$ 对应的近似 KL（~0.02）比 TRPO 略宽松——这在实践上被证明是合理的，因为 clip 机制本身比 TRPO 的硬约束更灵活。

### 2.2 为什么用 clip 而非直接约束 KL？

| 方案 | 优点 | 缺点 |
|------|------|------|
| TRPO（约束 KL） | 理论上界保证，数学优雅 | 需要二阶优化（共轭梯度），实现复杂 |
| PPO clip（用 ε） | 一阶方法，实现简单，计算高效 | 理论保证较弱，需要手动调 ε |
| PPO KL penalty | 自适应调整 β | 需要额外超参 β，实验上不比 clip 好 |

PPO 原始论文的实验表明 clip 版本优于 KL penalty 版本，且实现最简——这是 ε 成为标准的原因。

## 3. ε 的训练动力学

### 3.1 过小 ε：保守陷阱

当 $\varepsilon$ 过小（如 0.05）：

```
问题表现：
- 每次更新只能微调策略
- 需要更多外循环步骤才能收敛
- 在低数据量下可能"学不动"（SFT 模型成功率 4%，需要大量步骤才能提升）
- 但训练曲线平滑，几乎不会出现性能崩塌

何时适用：
- 大模型微调（如 OpenVLA-OFT 7B），参数多、稳健性要求高
- 接近最优解时的精细打磨阶段
- 高数据量设定，学习信号充足
```

**RIPT-VLA 中 ε 过小的风险**：1-shot SFT 从 4% 起步，若 ε=0.05，15 轮 RL 迭代可能不足以完成从 4% 到 97% 的跨越。

### 3.2 过大 ε：发散风险

当 $\varepsilon$ 过大（如 0.5）：

```
问题表现：
- 单步更新可能大幅改变策略分布
- 重要性比率 r 可达 2-3 倍，超出 clip 范围后梯度为零 → 浪费计算
- 可能出现"过冲"：一步更新后策略质量反而下降
- 在多任务场景中，某个任务的激进更新可能损害其他任务

何时（勉强）适用：
- 极小模型（参数少、容易拟合）
- 奖励信号极其干净（无噪声）
- 探索性实验阶段
```

### 3.3 最优区间的确定

PPO 论文推荐 $\varepsilon \in [0.1, 0.3]$，其中 $\varepsilon=0.2$ 是大多数任务的最优值。RIPT-VLA 沿用了 $\varepsilon=0.2$。

在 VLA 二元奖励场景下，ε 的选择需要额外考虑：

1. **优势的尺度**：二元奖励下优势 $A_k \in [-1, 1]$（最大值为 1，最小值为 -1），绝对值天然受限。这与 LLM RLHF 中奖励模型输出任意实数不同。**优势尺度小 → 即使 r 不被 clip，$r \cdot A$ 的绝对值也有限 → ε 的约束力在 VLA 中相对温和。**

2. **策略熵**：VLA 的动作空间（离散化 token）比 LLM 的文本空间小得多。策略分布的熵较低时，重要性比率 r 本身就不容易剧烈变化 → ε 的 clip 更不容易触发。

## 4. ε 与 DS-LOOP 三参数的联动

ε 不是孤立存在的，它与 $N$（内循环迭代数）、$K$（RLOO 组大小）和动态采样形成复杂的相互作用。

### 4.1 ε × N：clip 在迭代中的演化

RIPT-VLA 使用 $N=1$（OpenVLA-OFT）或 $N=20$（QueST）。

**当 N=1 时**：
- $\pi_\theta$ 只更新一次，偏离 $\pi_\psi$ 有限
- $r = \pi_\theta(a|c) / \pi_\psi(a|c)$ 接近 1
- clip 几乎不触发 → ε 的选择影响很小
- **结论**：$N=1$ 时 ε 可以取任意合理值（0.1-0.5），对结果影响微弱

**当 N=20 时**：
- 经过 19 次累积更新后，$\pi_\theta$ 已显著偏离 $\pi_\psi$
- iter 1-5：$r \approx 1$，clip 不触发
- iter 5-10：$r$ 开始偏离 1，clip 开始生效
- iter 10-20：$r$ 可能频繁触发 clip，ε 成为关键约束

```
N=20 时的 clip 触发率演化（示意）：
iter 1    ■□□□□□□□□□□□□□□□□□□□  5%
iter 4    ■■■□□□□□□□□□□□□□□□□□  15%
iter 8    ■■■■■□□□□□□□□□□□□□□□  25%
iter 12   ■■■■■■■■□□□□□□□□□□□□  40%
iter 16   ■■■■■■■■■■■■□□□□□□□□  60%
iter 20   ■■■■■■■■■■■■■■■■□□□□  80%
```

不同的 ε 在 iter 后半段影响截然不同：

| ε | iter 1-5 | iter 5-10 | iter 10-20 | 总体效果 |
|---|---------|----------|-----------|---------|
| 0.1 | 不触发 | 偶尔触发 | 频繁触发 → 有效更新少 | 保守，N=20 的复用效率打折扣 |
| 0.2 | 不触发 | 部分触发 | 频繁触发 | 平衡，标准选择 |
| 0.3 | 不触发 | 部分触发 | 触发但仍有学习空间 | 激进，N=20 利用率高但风险也高 |

**启示**：$N$ 和 ε 应该联动调优。如果增大 $N$（提高样本复用率），可能需要适当增大 ε 以确保在 iter 后期仍有有效更新。或者反过来：如果 ε=0.2 固定，$N$ 不应设置得过大于学完一批数据所需的最优迭代数。

### 4.2 ε × K：优势噪声与更新激进度的权衡

RLOO 的优势估计 $A_k = R_k - \frac{1}{K-1}\sum_{j\neq k} R_j$ 的方差随 K 减小而增大。

**低 K（K=2）时的噪声场景**：
- 二元奖励下，$A$ 只有三种可能：`{1, 0.5, -0.5, -1}`（K=2）或更少的离散值
- 如果一条轨迹碰巧失败（而它本应成功，只是环境随机性），$A_k = -0.5$ 会导致对该轨迹的不当惩罚
- **小 ε 保护模型免受噪声优势的过度影响**——即使 A 噪声大，ε 限制"最多改变 20%"

**高 K（K=8）时的低噪声场景**：
- 优势估计更可靠，$A$ 的连续值范围更大
- **可以承受更大的 ε**，因为方向更可信

```
推荐 ε 与 K 的配合：
K=2  → ε = 0.1-0.15  (保守：优势噪声大，别太信单次采样)
K=4  → ε = 0.15-0.25  (平衡)
K=8  → ε = 0.2-0.3    (激进：优势可靠，可以大步更新)
K=16 → ε = 0.25-0.35  (更激进)
```

### 4.3 ε × 动态采样：信号质量对 ε 选择的影响

动态采样过滤掉全零优势的上下文，确保进入训练的样本都有非零梯度信号。这意味着：

- **无需为"对抗噪声"而减小 ε**——噪声优势（如全零优势）已经被过滤
- 剩余的样本都是"有区分度的"：部分成功、部分失败
- 这些样本的优势 $A \neq 0$，方向可靠 → **可以承受较大的 ε**

这是一个被忽略的设计协同：**动态采样让 ε 可以取更大的值而不担心噪声**。

## 5. RIPT-VLA 中的 ε 选择实践

论文中使用 $\varepsilon = 0.2$（PPO 默认值），未做消融。以下是对这一选择的分析：

### 5.1 为什么 0.2 在 RIPT-VLA 中是合理的默认值

| 因素 | 对 ε 的影响 | 原因 |
|------|-----------|------|
| 二元奖励（优势 ≤ 1） | 降低 ε 的必要性 | 优势尺度小，clip 自然不频繁触发 |
| 动态采样 | 允许更大 ε | 噪声样本已过滤 |
| N=1（大模型） | ε 几乎无关 | r 始终 ≈ 1 |
| N=20（小模型） | ε 很关键 | 后期 clip 触发率决定有效学习量 |
| 多任务 | 偏好保守 ε | 避免单一任务过度更新 |
| 低数据量（1-5 shot） | 偏好保守 ε | 防止对少量样本过拟合 |

**综合判断**：0.2 在 RIPT-VLA 中是一个偏保守但不致于阻碍学习的选择。对于 N=20 的 QueST 实验，可能略偏保守（iter 15-20 的更新量被 clip 削减），但换来了训练的稳定性。

### 5.2 建议的消融实验

如果未来做 ε 的消融，建议测试以下配置：

| 实验 | ε | 预期效果 |
|------|---|---------|
| A | 0.1 | 训练更稳定，但 N=20 的迭代后期效率降低 |
| B | 0.2 | 基线（当前设置） |
| C | 0.3 | N=20 时样本利用率更高，但需监控多任务性能方差 |
| D | 0.1 → 0.3 (线性调度) | 前期保守（模型弱、优势噪声大），后期激进（模型强、方向可靠） |

## 6. 自适应 ε 的前景

静态 ε 的局限：训练全程使用同一个约束力度，无法适应策略能力的变化。

### 6.1 基于策略能力的自适应 ε

```
if 当前平均成功率 < 20%:
    ε = 0.1     # 模型弱、方向噪声大，保守
elif 当前平均成功率 < 70%:
    ε = 0.2     # 模型在成长，标准设置
else:
    ε = 0.3     # 模型强、方向可靠，激进
```

逻辑：当 SFT 模型只有 4% 成功率时，大部分"成功"是偶然的——对偶然成功过度鼓励可能导致策略走偏。小 ε 提供保护。当成功率提升到 50%+ 后，成功更多来自真正的能力，可以用大 ε 加速。

### 6.2 基于优势方差的 ε

```python
# 对每个 mini-batch 动态调整 ε
if advantage_variance > threshold:
    ε = min(0.3, ε_base * (1 / advantage_variance))
else:
    ε = ε_base
```

高方差优势 → 信号不可靠 → 缩小 ε 保护模型。

### 6.3 逐任务 ε（Per-Task Clip）

在多任务 RIPT-VLA 中，不同任务的成功率差异巨大。可以为每个任务分配独立的 ε：

- 高成功率任务（如 90%+）：大 ε（0.3），快速打磨
- 低成功率任务（如 30%）：小 ε（0.1），谨慎探索
- 中等任务（30-70%）：标准 ε（0.2）

但这增加了实现复杂度，且需要足够大的 batch 使每任务的统计有意义。

## 7. 总结与建议

### 7.1 核心结论

1. **RIPT-VLA 的 ε=0.2 是合理的默认值**：二元奖励 + 动态采样 + 多任务场景的综合考量。
2. **ε 与 N 的联动是最重要的调优杠杆**：N=20 时 ε=0.2 可能偏保守，建议尝试 ε=0.25-0.3。
3. **ε 与 K 呈正相关**：K 越大（优势越可靠），ε 可以越大。
4. **动态采样为更大 ε 创造了条件**：噪声已过滤，剩余信号可信。
5. **静态 ε 是当前最优实践，但自适应 ε 有探索价值**。

### 7.2 对 RIPT-VLA 下一步实验的建议

| 优先级 | 建议 | 原因 |
|--------|------|------|
| 高 | 消融 ε ∈ {0.1, 0.2, 0.3} 在 N=20 下的效果 | 最直接的杠杆点 |
| 中 | 测试 ε 线性调度（0.1 → 0.3） | 低实现成本，理论合理 |
| 低 | 逐任务 ε | 实现复杂，边际收益存疑 |
