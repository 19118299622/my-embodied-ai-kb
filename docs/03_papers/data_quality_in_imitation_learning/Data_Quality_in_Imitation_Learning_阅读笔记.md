# Data Quality in Imitation Learning：阅读笔记

> 原文：`papers/NeurIPS-2023-data-quality-in-imitation-learning-Paper-Conference.pdf`  
> 当前进度：已完成调研级总体导读；已讨论“动作一致性”的经验衡量；尚未逐节精读公式、理论证明和全部实验细节。

## 调研级导读

### 研究问题

论文关注的不是如何设计新的模仿学习算法，而是：在训练算法固定时，什么样的示教数据更容易训练出可靠的闭环策略？

作者认为，模仿学习的典型失败链条是：

```text
动作预测误差
→ 到达训练集中少见的状态
→ 后续动作误差累积
→ 任务失败
```

因此，数据质量应与“训练策略在实际闭环执行中是否偏离示教数据分布”相关，而不能只看示教者是否熟练或状态覆盖是否足够广。

### 核心定义

论文把数据集 `DN` 的质量定义为训练策略与示教策略状态访问分布之间负的散度：

```text
Q(DN; πE, A) = -Df(ρπA(s), ρπE(s))
```

- `πE`：生成数据的示教策略；
- `A`：训练算法；
- `πA = A(DN)`：利用数据集训练得到的策略；
- `ρπ(s)`：策略执行时访问状态的分布；
- `Df`：f-散度。

质量越高，训练策略的状态访问分布越接近示教策略。由此可见，论文中的数据质量不是完全绝对的静态属性；它依赖示教者、数据量、训练算法和环境动力学。

### 两项关键质量性质

1. **动作偏差（Action Divergence）**：学习策略和示教策略在相同状态下的动作分布差异。动作不稳定、频繁修正、犹豫或多种冲突操作方式，都会使模型更难学习稳定映射，从而加剧闭环偏移。
2. **转移多样性（Transition Diversity）**：给定状态—动作对后，下一状态分布的变化范围；可理解为环境扰动或系统随机性。适度变化可能扩大有效状态覆盖、提高鲁棒性；过大变化或数据不足则会造成覆盖稀疏。

### 核心结论

**状态多样性不等于数据质量。**

- 由环境系统噪声带来的状态扩张，在保持示教动作一致时，适量可能有益；
- 由示教动作噪声带来的状态扩张，会同时增加动作不一致性，尤其在小数据量时通常有害；
- 更合理的目标是：保持动作一致性，并获得不过度稀疏的有效状态覆盖。

### 实验与证据

论文在 2D PMObstacle 和 RoboMimic Square 中，分别向系统动力学和示教策略注入不同强度的高斯噪声，并比较不同数据量下行为克隆策略的表现；还分析了 RoboMimic Square、Can 中的人类示教数据。

实证发现：适度系统噪声可提高鲁棒性，过量会因样本覆盖稀疏而损害表现；相近的状态扩张若来自示教动作噪声，通常比系统噪声更糟；小数据量下，动作噪声的负面影响更显著；人类示教中，较高动作方差、较长轨迹常伴随较低成功率，但这属于相关性证据。

## 已讨论问题：动作一致性如何衡量？

论文用**相近状态对应动作的离散程度**，近似动作一致性。

### 经验估计流程

1. 对每个状态 `s`，在数据集中找距离小于阈值 `ε` 的邻近状态；
2. 收集这些邻近状态对应的动作；
3. 计算该组动作的方差；
4. 对整个数据集的局部动作方差求平均，得到 `Action Variance`。

```text
相近状态 → 动作几乎相同 → 动作方差低 → 一致性高
相近状态 → 动作方向/幅度差异很大 → 动作方差高 → 一致性低
```

它想近似的是示教策略给定状态时的动作熵 `H(πE(a|s))`。真实数据通常只有有限样本、没有完整的示教动作分布，因此以邻近状态的多个样本来估计。

### 限制

- **状态表示很关键**：原始图像距离不一定反映任务语义相似性；多模态/VLA 场景通常需要较好的视觉或多模态表征来定义“邻近”。
- **动作需要按量纲处理**：不同关节、夹爪状态、末端位姿应归一化或分维度统计。
- **单步指标有盲点**：无法充分识别长期策略分叉；两条轨迹可能单步相近但后续意图不同，也可能路径不同但都有效。
- 因而更适合诊断动作抖动、犹豫与不稳定，不能单独作为整条轨迹质量的最终判定。
