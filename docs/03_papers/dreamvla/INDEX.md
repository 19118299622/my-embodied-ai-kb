## 一句话定位

在 VLA 中集成**综合世界知识预测**（动态区域引导的动态 / 空间 / 语义三类知识），通过逆动力学建模形成"感知—预测—动作"闭环；采用块级结构化注意力隔离三类信息、扩散 Transformer 解耦动作表示。真机任务成功率 76.7%，CALVIN ABC-D 平均长度 4.44。
