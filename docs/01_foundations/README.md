# 01 Foundations

该目录用于系统学习和稳定基础知识。

长期学习主题默认采用两个文件：

```text
主题名称/
├── 学习规划与进度.md
└── 长期学习笔记.md
```

教学节奏：

1. 完成一讲；
2. 进入问答区；
3. 澄清关键疑问；
4. 把重要结论和误区修正写回笔记；
5. 再进入下一讲。

可使用：

- [`../../templates/LEARNING_PLAN_TEMPLATE.md`](../../templates/LEARNING_PLAN_TEMPLATE.md)
- [`../../templates/LONG_TERM_NOTES_TEMPLATE.md`](../../templates/LONG_TERM_NOTES_TEMPLATE.md)
